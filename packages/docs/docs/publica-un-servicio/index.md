# Publica un servicio

Esta guía lleva a un publisher de cero a un servicio vivo que los asistentes pueden descubrir y pagar por llamada. Todo usa [`kiba-sdk`](https://www.npmjs.com/package/kiba-sdk). Los ejemplos de [`packages/demo-agents/`](https://github.com/CoKeFish/kiba/tree/main/packages/demo-agents) son plantillas para copiar.

| Paso | Página |
|---|---|
| 1. Crear y registrar el servicio | [Quickstart](/publica-un-servicio/quickstart) |
| 2. Escribir el handler y fijar el precio | [Handler y precios](/publica-un-servicio/handler-y-precios) |
| 3. Publicarlo en una URL estable | [Despliegue](/publica-un-servicio/despliegue) |
| 4. Entender cómo te encuentran y te pagan | [Descubrimiento y llamadas](/publica-un-servicio/descubrimiento-y-llamadas) · [Cómo cobras](/publica-un-servicio/como-cobras) |
| 5. Proteger tu nombre | [Nombres y confianza](/publica-un-servicio/nombres-y-confianza) |
| 6. Seguir ganancias y liquidaciones | [Panel de publisher](/publica-un-servicio/panel-de-publisher) |
| 7. Prepararte para producción | [Ir a mainnet](/publica-un-servicio/mainnet) |

Si algo falla, revisa [Problemas frecuentes al publicar](/publica-un-servicio/problemas-frecuentes).
