# Estado del proyecto

Kiba corre hoy en la **testnet de Stellar**. Los saldos, los pagos y las ganancias son de prueba y **no tienen valor real**.

Para probar el flujo completo no necesitas dinero: las cuentas de testnet se fondean gratis. Ver [Testnet](/stellar/testnet).
