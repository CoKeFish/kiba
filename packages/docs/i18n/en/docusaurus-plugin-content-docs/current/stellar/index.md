# Why Stellar

Kiba needs to charge fractions of a cent per call, in dollars, without interrupting the conversation. That shapes the choice of network:

| Need | What Stellar brings |
|---|---|
| Micropayments without volatility | **Native USDC**: a first-class stablecoin, dollar accounting |
| Charge per call, not per subscription | **Minimal fees**: fractions of a cent per operation |
| Payment that doesn't interrupt the chat | **Fast finality**: settlement in ~5 seconds |
| On- and off-ramps to local currency | **Anchors / fiat**: ramps to local currencies (for Kiba, the Colombian peso; see [Roadmap](/recursos/hoja-de-ruta)) |
| Programmable registry | **Soroban**: Rust contracts for the registry (and, depending on the design, escrow and split) |
| Strategic fit | Agent-to-agent commerce (*agentic commerce*) is a focus of the Stellar ecosystem |
