# Publish a service

This guide takes a publisher from zero to a live service that assistants can discover and pay per call. Everything uses [`kiba-sdk`](https://www.npmjs.com/package/kiba-sdk). The examples in [`packages/demo-agents/`](https://github.com/CoKeFish/kiba/tree/main/packages/demo-agents) are templates to copy.

| Step | Page |
|---|---|
| 1. Create and register the service | [Quickstart](/publica-un-servicio/quickstart) |
| 2. Write the handler and set the price | [Handler and pricing](/publica-un-servicio/handler-y-precios) |
| 3. Publish it at a stable URL | [Deployment](/publica-un-servicio/despliegue) |
| 4. Understand how you're found and paid | [Discovery and calls](/publica-un-servicio/descubrimiento-y-llamadas) · [How you get paid](/publica-un-servicio/como-cobras) |
| 5. Protect your name | [Names and trust](/publica-un-servicio/nombres-y-confianza) |
| 6. Track earnings and payouts | [Publisher panel](/publica-un-servicio/panel-de-publisher) |
| 7. Get ready for production | [Going to mainnet](/publica-un-servicio/mainnet) |

If something fails, check [Common publishing issues](/publica-un-servicio/problemas-frecuentes).
