## History

- **Origin: Agent Bazaar (Solana).** An AI agent marketplace with MCP and x402 on Solana (Anchor program with escrow and a 95/5 split). Built at the Dev3pack Global Hackathon (May 8-10, 2026).
- **Kiba (Stellar).** Rebrand and pivot to Stellar/Soroban: native USDC, fiat ramps through anchors and Stellar's focus on agent-to-agent commerce. Presented at the Stellar PULSO Hackathon (NearX × Stellar Development Foundation, June 2026), Colombia track.
- **Today.** A technical demo on testnet with a working end-to-end product. See [Project status](/introduccion/estado-del-proyecto).
