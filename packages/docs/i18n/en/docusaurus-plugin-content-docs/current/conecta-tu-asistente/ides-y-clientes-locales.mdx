# IDEs and local clients

For clients that run MCP servers locally, Kiba ships `kiba-mcp`, a small adapter that talks to the gateway on your behalf. The first time, it signs in through the browser and stores a local token.

## Option A — Windows installer {/* #opción-a--instalador-de-windows */}

Download the one-click installer from the [latest release](https://github.com/CoKeFish/kiba/releases/latest) (`Kiba-Installer-x64-setup.exe`). It installs the `kiba` MCP server in **Claude Desktop, Cursor and Claude Code** automatically. Restart the client when it finishes.

- It detects which MCP clients you have, backs up your configuration (`*.json.bak`) before touching anything and inserts only the `mcpServers.kiba` block, preserving the rest.
- If Node.js is missing, it detects it and offers to open [nodejs.org](https://nodejs.org) (`npx -y kiba-mcp` doesn't run without it).
- Built with Tauri 2 (~3-5 MB binary).

:::warning[Windows SmartScreen]
It may warn you because the installer isn't signed yet: **More info → Run anyway**. It's built and published from the public repository.
:::

## Option B — Manual setup {/* #opción-b--configuración-manual */}

Works on macOS, Linux and Windows. Add this block to your client's MCP configuration:

```json
{
  "mcpServers": {
    "kiba": {
      "command": "npx",
      "args": ["-y", "kiba-mcp"]
    }
  }
}
```

In `claude_desktop_config.json`, inside the app's configuration folder, with the block above.

<TabItem value="codex" label="Codex CLI">

In `~/.codex/config.toml`:

```toml
[mcp_servers.kiba]
command = "npx"
args = ["-y", "kiba-mcp"]
```

Restart the client. On the first call:

1. The adapter detects there's no session and opens the browser at the gateway.
2. You sign in (or create an account) and click **Authorize**.
3. The page says you can close the tab. The token is stored at `~/.config/kiba/token.json` (permissions 600).

## Browserless use

For CI, servers or automation, set an API key; the adapter skips OAuth. Create it in the dashboard (**Credentials**) or with [`POST /v1/api-keys`](/api/autenticacion#api-keys).

```json
{
  "mcpServers": {
    "kiba": {
      "command": "npx",
      "args": ["-y", "kiba-mcp"],
      "env": { "KIBA_API_KEY": "sk_live_…" }
    }
  }
}
```

## Environment variables {/* #variables-de-entorno */}

| Variable | Default | Purpose |
|---|---|---|
| `KIBA_URL` | `https://api.kiba.tools` | Gateway to talk to (self-hosted gateways) |
| `KIBA_API_KEY` | unset | Long-lived key; if set, OAuth is skipped |
| `KIBA_TOKEN_PATH` | `~/.config/kiba/token.json` | Where the OAuth token is stored |
| `KIBA_CLIENT_NAME` | `kiba-mcp` | Name shown on the consent screen |

To use a self-hosted gateway, point `KIBA_URL` at it. See [Self-hosting and development](/recursos/self-hosting).
