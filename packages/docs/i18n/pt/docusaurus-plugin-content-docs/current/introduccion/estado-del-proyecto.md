# Status do projeto

A Kiba roda hoje na **testnet da Stellar**. Saldos, pagamentos e ganhos são de teste e **não têm valor real**.

Você não precisa de dinheiro para testar o fluxo completo: as contas da testnet são financiadas de graça. Veja [Testnet](/stellar/testnet).
