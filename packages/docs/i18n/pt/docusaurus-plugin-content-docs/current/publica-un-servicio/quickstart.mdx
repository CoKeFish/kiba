# 🚀 Quickstart

## Requisitos

- **Node.js 18** ou superior.
- Uma **conta Stellar** para o serviço. Na testnet o SDK a cria e a financia com o friendbot; na mainnet você mesmo a financia.
- <TW /> Uma **API key da Trustless Work** (BackOffice dApp) para que o escrow on-chain possa liquidar.
- O **id do contrato de registro** e a **chave pública da plataforma** da rede alvo (veja [Testnet](/stellar/testnet)).

## Estrutura do serviço

```bash
mkdir my-service && cd my-service
npm init -y
npm install kiba-sdk express
```

```ts title="src/index.ts"
import { AgentProvider, loadOrCreateKeypair } from 'kiba-sdk';

const provider = new AgentProvider({
  wallet: loadOrCreateKeypair(process.env.KEYPAIR_PATH ?? './data/wallet.json'),

  service: 'sentiment',                       // id único, máx. 32 caracteres
  pricePerCall: 0.002,                        // USDC
  description: 'Sentiment analysis (positive/negative/neutral). Input: { text: string }',
  endpoint: process.env.PUBLIC_ENDPOINT ?? 'http://localhost:5010',

  network: (process.env.STELLAR_NETWORK as 'testnet' | 'mainnet') ?? 'testnet',
  contractId: process.env.STELLAR_CONTRACT_ID,
  trustlessWork: {                            // ⚠️ TW
    apiKey: process.env.TRUSTLESS_WORK_API_KEY,
    platformAddress: process.env.KIBA_PLATFORM_ADDRESS,
  },

  // Aceita chamadas assinadas rápidas do gateway. Omita para exigir escrow em toda chamada.
  platform: process.env.KIBA_PLATFORM_PUBLIC_KEY
    ? { publicKey: process.env.KIBA_PLATFORM_PUBLIC_KEY }
    : undefined,
});

provider.serve(async (req: { text: string }) => {
  const score = analyze(req.text);            // seu modelo / lógica de negócio
  return { label: score > 0 ? 'positive' : 'negative', score };
});

(async () => {
  await provider.bootstrap();                  // financia + registra on-chain
  await provider.listen(Number(process.env.PORT ?? 5010));
})();

function analyze(text: string): number {
  return /good|great|love/i.test(text) ? 1 : -1;
}
```

Na primeira execução, `bootstrap()` financia a conta (friendbot na testnet), configura a trustline de USDC e registra `sentiment` no registro on-chain. **A partir desse momento o serviço é descobrível.** Não há nada para enviar a ninguém.
