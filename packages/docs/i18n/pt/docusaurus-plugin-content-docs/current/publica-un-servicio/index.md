# Publique um serviço

Este guia leva um publisher do zero a um serviço no ar que os assistentes podem descobrir e pagar por chamada. Tudo usa o [`kiba-sdk`](https://www.npmjs.com/package/kiba-sdk). Os exemplos de [`packages/demo-agents/`](https://github.com/CoKeFish/kiba/tree/main/packages/demo-agents) são modelos para copiar.
