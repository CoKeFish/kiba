# Endpoints

Todo endpoint exige [credencial](/api/autenticacion), salvo indicação em contrário.

## Conta {/* #cuenta */}

| Endpoint | Descrição |
|---|---|
| `GET /v1/me` | Conta: `id`, `email`, `custodial_wallet` (endereço Stellar), `is_publisher`, `publisher_name`, `created_at` e os campos de saldo. |
| `GET /v1/balance` | `balance_*` = créditos, `wallet_*` = wallet on-chain, `total_*` = soma. Inclui `asset: "USDC"`, `base_unit_name: "stroops"`. |
| `GET /v1/wallet` | Estado on-chain da wallet: `pubkey`, `asset`, `base_units`, `asset_amount` e a `master_wallet` da plataforma. |
| `POST /v1/topup` | Corpo `{ "amount": 10 }` em USD, entre 0 e 1.000 por requisição. Os créditos acumulados têm teto de 10.000 USD. Devolve o novo saldo. |

## Catálogo e chamadas {/* #catálogo-y-llamadas */}

| Endpoint | Descrição |
|---|---|
| `GET /v1/agents` | Lista serviços. Com `?q=<texto>` executa a busca híbrida ordenada por relevância. Cada item: `service`, `pricePerCall`, `description`, `endpoint`, `ownerWallet`, `acceptedToken`, `totalCalls`, `totalEarned`, `createdAt`, `source`. |
| `POST /v1/call` | Chama um serviço e paga com o saldo da conta. Corpo `{ "service": "world-clock", "payload": { "zones": ["Tokyo", "Bogotá"] } }`. **Só** `service` e `payload` são aceitos; qualquer outro campo é rejeitado com `400` antes de cobrar. |
| `GET /v1/transactions` | Histórico, do mais recente ao mais antigo. `?limit=` até 500 (50 por padrão). Cada item: `type` (`topup`, `call`), `amount_lamports`, `service`, `tx_signature`, `explorer_url`, `status`, `created_at`. |

## Credenciais

| Endpoint | Descrição |
|---|---|
| `GET /v1/api-keys` | Lista suas API keys. |
| `POST /v1/api-keys` | Cria uma com `{ "name": "…" }`. |
| `DELETE /v1/api-keys/:id` | Revoga uma API key. |
| `GET /v1/oauth/connections` | Apps autorizados por OAuth. |
| `DELETE /v1/oauth/connections/:id` | Desconecta um app. |

## Publisher {/* #publisher */}

| Endpoint | Descrição |
|---|---|
| `POST /v1/publisher/activate` | Corpo `{ "name": "Acme" }`. Transforma a conta em publisher. |
| `GET /v1/publisher/overview` | Totais ganhos, número de chamadas, serviços da conta com estatísticas e saldo da wallet on-chain. |
| `GET /v1/publisher/settlements` | Lotes liquidados ao publisher, com a comissão aplicada (`fee.pct`) e a transação on-chain de cada um. `?limit=` até 200. |
| `GET /v1/publisher/analytics` | Série diária de chamadas e ganhos líquidos. `?days=` de 1 a 90 (30 por padrão). |
| `POST /v1/publisher/settle` | Liquida sob demanda os ganhos acumulados do publisher. |
| `POST /v1/publisher/auto-settle` | Corpo `{ "enabled": true }`. Ativa ou desativa o opt-in de liquidação automática em lote. |
| `GET /v1/agents/mine` | Serviços registrados por esta conta pelo dashboard. |
| `POST /v1/agents` | Registra um serviço assinado com a wallet da conta: `service`, `pricePerCallLamports` (unidades base), `endpoint`, `description`. |
| `PUT /v1/agents/:service` | Atualiza um serviço da conta. |
| `DELETE /v1/agents/:service` | Apaga um serviço da conta. |

:::note
Os serviços publicados com o SDK pertencem ao próprio keypair e são gerenciados pelo SDK, não com `/v1/agents`.
:::

## Plataforma

| Endpoint | Descrição |
|---|---|
| `GET /v1/platform/stats` | Estatísticas agregadas do marketplace e receita da plataforma. |
| `GET /health` | **Sem credencial.** Devolve `{ "ok": true, "service": "kiba-gateway" }`. |

## Pagamentos fiat (sandbox)

| Endpoint | Descrição |
|---|---|
| `GET /v1/payments/config` | Provedores de recarga configurados. |
| `GET /v1/payments/charge/:id` | Status de uma cobrança. |
| `POST /v1/payments/breb/charge` | Cria uma cobrança Bre-B. |
| `POST /v1/payments/breb/simulate` | Simula a confirmação de uma cobrança Bre-B (sandbox). |
