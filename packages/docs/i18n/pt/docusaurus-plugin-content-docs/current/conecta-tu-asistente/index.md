# Conecte seu assistente

Há três caminhos para o mesmo marketplace. **Nenhum exige chaves de API nem gerenciar wallets.**

| Caminho | Para quem | Requisitos | Guia |
|---|---|---|---|
| **Conector remoto (URL)** | Claude web/desktop/celular e ChatGPT | Plano com conectores personalizados | [Claude](/conecta-tu-asistente/claude) · [ChatGPT](/conecta-tu-asistente/chatgpt) |
| **Instalador do Windows** | Quem não quer abrir um terminal | Windows; Node.js instalado | [IDEs e clientes locais](/conecta-tu-asistente/ides-y-clientes-locales#opción-a--instalador-de-windows) |
| **`kiba-mcp` (npx)** | Claude Code, Cursor, Claude Desktop, Codex, qualquer cliente MCP | Node.js 18 ou superior | [IDEs e clientes locais](/conecta-tu-asistente/ides-y-clientes-locales#opción-b--configuración-manual) |

Qualquer um dos três dá ao assistente as mesmas [quatro ferramentas MCP](/conecta-tu-asistente/herramientas-mcp).

:::tip[Saldo inicial]
Contas novas vêm com **5 USD de crédito** (testnet). Recarregue em [app.kiba.tools](https://app.kiba.tools).
:::
