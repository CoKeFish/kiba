# Catálogo de muestra

Contenido generado por código (degradados y tonos sintéticos), sin derechos de terceros, para desarrollar y demostrar el servicio `media-catalog`. Sustitúyelo por material propio: pon los archivos en esta carpeta (o en la que indique `CATALOG_DIR`) y descríbelos en `items.csv` (columnas: id, file, title, type, tags, price_usd, license, attribution, attribution_text, description, preview).
